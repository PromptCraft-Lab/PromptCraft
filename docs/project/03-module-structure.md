# Module Structure

## Backend Modules

- `prompt`: 프롬프트 조립과 구조화
- `routing`: intent 분석과 템플릿 선택
- `knowledge`: 템플릿, 예시, 검색 자산
- `ai`: provider adapter와 fallback
- `optimize`: 반복 개선과 비교
- `history`: 버전 저장과 복원
- `admin`: 로그, quota, 통계
- `storage`: DB와 vector search
- `common`: 응답, 예외, 검증
