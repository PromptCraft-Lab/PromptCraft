# Core Conventions

## Principles

- 코드는 읽기 쉬워야 한다.
- 요청 범위를 넘지 않는다.
- 문서와 구현은 항상 맞아야 한다.
- 추측성 기능은 넣지 않는다.
- 변경은 작은 단위로 한다.
- 앱 코드는 TypeScript를 우선한다.
- JavaScript는 빌드/도구 설정처럼 경계가 분명한 곳에만 쓴다.

## AI Work

- 먼저 생각하고, 그 다음 수정한다.
- 관련 없는 파일은 건드리지 않는다.
- `apply_patch`를 우선한다.
- 결과는 검증 가능한 상태로 남긴다.
- 같은 이슈에 여러 접근이 가능하면 비교 후 이유를 기록한다.
