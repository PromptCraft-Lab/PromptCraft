# Worktree Conventions

워킹트리 사용 기준의 원문이다.
실행 전에 빠르게 점검할 항목은 `docs/ops/workflows/working-tree.md`를 참고한다.

## Rules

- 작업 시작 전 현재 상태를 확인한다.
- 변경은 필요한 파일에만 만든다.
- 사용하지 않는 임시 파일은 남기지 않는다.
- 작업이 끝나면 문서와 코드 상태를 같이 확인한다.

## Comparison

- 같은 이슈에 대해 기본적으로 2개만 비교한다.
- 변경 파일 수, 검증 결과, 변경량을 함께 본다.
- 채택 이유는 dev log에 짧게 남긴다.
