# Issue Conventions

이 문서는 이슈 작성 기준을 정리한다.
실행 체크리스트는 `docs/ops/workflows/issue.md`를 참고한다.

## Rules

- 이슈는 하나의 목적만 담는다.
- 버그, 기능, 작업 이슈를 섞지 않는다.
- 제목은 짧고 목적이 드러나게 쓴다.
- 재현 절차나 기대 결과가 있으면 함께 적는다.
- 관련 문서와 검증 방법을 남긴다.

## Suggested Types

- `bug`
- `enhancement`
- `task`

## Required Content

- 요약
- 목적 또는 재현 정보
- 범위
- 검증 방법
- 관련 문서
