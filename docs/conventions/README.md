# Conventions

PromptCraft 개발과 협업에서 지켜야 할 기준 문서 모음이다.
기본 작업은 루트 `agent.md`만으로 시작하고, 규칙 확인이 필요할 때만 이 폴더를 참조한다.

## Source of Truth

- 브랜치, PR/MR, 워킹트리, 터미널 관련 세부 기준은 이 폴더의 문서를 우선한다.
- `docs/ops/workflows/`는 실행 체크리스트이며, 세부 기준은 여기로 연결한다.

## Usage Rule

- 규칙 충돌이 있으면 `agent.md`를 우선한다.
- 특정 상황의 기준이 필요할 때만 해당 문서를 연다.
