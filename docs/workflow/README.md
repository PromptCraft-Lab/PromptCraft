# Workflow Docs

PromptCraft의 작업 실행 흐름을 모아두는 보조 문서 허브다.
기본 작업은 루트 `agent.md`만으로 진행하고, 빌드/리뷰/릴리스 절차가 필요할 때만 이 폴더를 참조한다.

## Available Files

1. `build.md`
2. `review.md`
3. `release.md`

## Boundary

- 이 폴더는 작업을 어떻게 시작하고 검토하고 공개하는지에만 집중한다.
- 브랜치, 워킹트리, PR/MR, 터미널, 체크 규칙은 `docs/ops/`와 `docs/conventions/`를 본다.

## Usage Rule

- 작업 흐름이 필요할 때만 세부 문서를 연다.
- 세부 문서가 필요 없으면 `agent.md`의 작업 원칙을 우선한다.
