# Operations Docs

이 폴더는 PromptCraft의 운영 절차와 실행 체크리스트를 담는 보조 자료다.
기본 작업은 루트 `agent.md`만으로 시작하고, 운영 세부가 필요할 때만 이 폴더를 연다.

## Files

- `docs/ops/agent/agent.md`
- `docs/ops/agent/README.md`
- `docs/ops/agent/harness-engineering.md`
- `docs/ops/agent/skills/README.md`
- `docs/ops/workflows/working-tree.md`
- `docs/ops/workflows/issue.md`
- `docs/ops/workflows/pr-mr.md`
- `docs/ops/workflows/github-action-checks.md`
- `docs/ops/workflows/terminal.md`
- `docs/ops/workflows/verification.md`

## Purpose

- 작업 전에 확인할 운영 체크리스트를 제공한다.
- 브랜치, 워킹트리, PR/MR, 터미널, 체크 항목을 실행 관점에서 정리한다.
- 하네스 규칙과 반복 작업 지식은 agent/skills 문서로 분리한다.
- 이슈 작성 기준은 issue workflow로 분리한다.
- 세부 기준은 `docs/conventions/`의 문서를 참조한다.

## Update Rule

운영 절차가 추가되면 이 파일의 파일 목록과 설명을 함께 갱신한다.
