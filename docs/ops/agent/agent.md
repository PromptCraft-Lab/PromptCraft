# Agent Operations

이 문서는 루트 `agent.md`를 따르는 짧은 운영 보조 문서다.
새 작업을 시작할 때 필요한 최소 점검만 적는다.

## Quick Checks

- 현재 작업이 루트 `agent.md`의 범위 안에 있는지 확인한다.
- 관련 문서가 정말 필요한지 먼저 판단한다.
- 변경 범위가 넓지 않은지 확인한다.
- 관련 없는 파일이 섞이지 않았는지 확인한다.
- UTF-8 인코딩이 필요한 경우 먼저 맞춘다.
- 테스트나 빌드가 있으면 변경 뒤 확인한다.
- PR 또는 커밋 전에 변경 요약을 정리한다.
- 워킹트리 비교가 필요한 작업인지 먼저 본다.
- 한 브랜치에 하나의 작업만 담겼는지 확인한다.
- PR/MR 설명에 검증 결과가 들어갔는지 확인한다.

## Operability Rules

- 브랜치 규칙은 문서와 맞아야 한다.
- PR 템플릿은 가능한 한 사용한다.
- 관리자용 변경과 일반 사용자 변경은 분리한다.
- 작업 로그나 노트가 필요하면 관련 문서에 남긴다.

## Failure Modes

- 루트 가이드와 서로 다른 규칙을 따르는 상태
- 작업 범위가 넓어져서 원래 의도가 흐려지는 상태
- 문서와 구현이 서로 다른 내용을 말하는 상태
