# Agent Ops

이 폴더는 PromptCraft의 하네스 문서를 모아둔다.

## Files

- `agent.md`
- `harness-engineering.md`
- `skills/README.md`

## Use

- 루트 `agent.md`는 모든 작업의 기본 진입점이다.
- 이 폴더의 문서는 하네스 구조와 반복 작업 지식을 보조한다.
- `harness-engineering.md`는 하네스의 레버를 저장소 규칙으로 바꿔서 설명한다.
- `skills/README.md`는 반복 작업용 스킬 카탈로그다.

## Rule

- 공통 규칙은 루트 `agent.md`에 둔다.
- 반복 작업의 절차는 skill 문서로 내린다.
- 검증과 완료 조건은 workflow 문서와 함께 본다.
