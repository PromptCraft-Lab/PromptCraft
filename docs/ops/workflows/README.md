# Ops Workflows

운영 실행 체크리스트를 모아두는 보조 허브다.
기본 작업은 루트 `agent.md`만으로 진행하고, 실행 전에 빠르게 점검할 항목이 필요할 때만 이 폴더를 참조한다.

## Files

- `docs/ops/workflows/working-tree.md`
- `docs/ops/workflows/issue.md`
- `docs/ops/workflows/pr-mr.md`
- `docs/ops/workflows/github-action-checks.md`
- `docs/ops/workflows/terminal.md`
- `docs/ops/workflows/verification.md`

## Boundary

- 이 폴더는 실제 작업 전에 확인할 체크포인트를 정리한다.
- 세부 규칙의 기준 원문은 `docs/conventions/`를 우선한다.
- 완료 직전 검증 기준은 `verification.md`를 따른다.
- 이슈 작성 체크는 `issue.md`를 따른다.

## Purpose

- 브랜치와 워킹트리 사용 전 점검 항목을 정리한다.
- PR/MR과 검증 흐름을 실행 관점에서 확인한다.
- 작업 전후 체크를 한 문서에서 확인할 수 있게 한다.
