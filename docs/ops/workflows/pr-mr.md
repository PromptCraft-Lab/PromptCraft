# PR and MR Rules

PromptCraft에서 Pull Request와 Merge Request를 같은 기준으로 관리한다.

## Rules

- 하나의 PR/MR은 하나의 주제만 담는다.
- 문서와 코드가 함께 바뀌면 같은 PR/MR에 묶는다.
- 설명에는 무엇을, 왜, 어떻게 바꿨는지 적는다.
- 검증 결과를 함께 남긴다.
- 코드리뷰 요청은 가능한 한 자동화한다.
- 변경 범위에 따라 관련 폴더 담당자가 확인할 수 있어야 한다.

## Required Content

- 변경 요약
- 관련 문서
- 확인 방법
- 남은 작업
- 코드리뷰 포인트

## Prohibited

- 여러 주제를 한 번에 섞는 것
- 검증 없이 올리는 것
- 문서 수정 없이 계약만 바꾸는 것

## Validation

- 리뷰어가 맥락 없이도 변경 범위를 이해할 수 있다.
- 완료 여부를 확인할 수 있다.
